# HireMind AI Candidate Guide
## Applying, Tracking Applications, & Coding Sandboxes

This guide helps candidates navigate applications and complete technical coding tasks.

---

## 1. Registering & Applying
- Create a Candidate Profile using an active email address.
- Upload your resume PDF file. The portal builds a matching profile index automatically.
- Review matching job recommendations on your dashboard.

---

## 2. Tracking Applications
- Monitor the stage status of submitted applications (Screening, Technical Interview, Offer).
- Receive real-time chat notifications from the AI Recruitment Copilot helper.

---

## 3. Completing Coding Assessments
When invited to a technical coding assessment:
1. Navigate to the **Coding Sandbox** dashboard.
2. Review task descriptions, runtime constraints, and allowed languages (Python, Rust, Go).
3. Draft code directly in the browser sandbox editor.
4. Click **Run Tests** to validate correctness. Code compiler processes are container-sandboxed for system security.
